# 🎓 SmartCampus
### *Smarter Campus. Faster Resolutions.*

A modern **MERN Stack Campus Complaint Management System** that simplifies complaint submission, tracking, and resolution through a centralized digital platform.

<p align="center">

  <b>⚡ React · Node.js · Express · MongoDB</b>

</p>

---

### ✨ Features

- 🎯 **Smart Dashboard** — Interactive student and admin dashboards.
- 📝 **Complaint Management** — Submit and manage campus complaints.
- 📊 **Live Insights** — Visualize complaint statistics and categories.
- 🔄 **Status Tracking** — Track complaints from submission to resolution.
- 👥 **User Management** — Manage platform users and review feedback.
- 🔐 **Secure Access** — JWT authentication and role-based authorization.
- 🎨 **Premium UI** — Modern dark theme with a clean dashboard experience.

### 🛠️ Tech Stack

| Frontend | Backend | Database |
|---|---|---|
| React + Vite | Node.js + Express | MongoDB |
| CSS3 + Axios | REST APIs + JWT | Mongoose |

### 🚀 Getting Started

**1. Clone the repository**
```bash
git clone YOUR_REPOSITORY_URL
cd SmartCampus
```

**2. Install dependencies**
```bash
cd backend
npm install
```

```bash
cd ../frontend
npm install
```

**3. Configure your environment**

Create `backend/.env` with the variables required by your backend, such as your MongoDB connection string, JWT secret, and port.

**4. Run the application**

Backend terminal:
```bash
cd backend
npm run dev
```

Frontend terminal:
```bash
cd frontend
npm run dev
```

Open the local URL displayed by Vite in your browser.
